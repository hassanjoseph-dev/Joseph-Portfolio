# Student Portfolio and Academic Management Website (COS 106)

Multi-page responsive site: Home, About, Projects, Academic Planner, Contact.
Built with semantic HTML5, one external stylesheet (`css/style.css`) and vanilla JavaScript (`js/script.js`).
Colours: Black `#0A0A0B` + Signal Red `#E11D2E` (change them in `:root` at the top of `style.css`).

## Host it free with GitHub Pages
1. Create a repository on https://github.com/hassanjoseph-dev and upload everything in this folder (keep `index.html` at the top level).
2. Repository **Settings > Pages > Build and deployment**: Source = *Deploy from a branch*, Branch = `main` / `(root)`, then Save.
3. After a minute your live link appears: `https://hassanjoseph-dev.github.io/<repository-name>/`.
4. Submit the live link and the repository link.
